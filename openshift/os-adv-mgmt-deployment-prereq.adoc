= 為 Kubernetes 部署高階叢集管理
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
本節介紹使用NetApp在 Red Hat OpenShift 上對 Kubernetes 進行進階叢集管理。



[[prerequisites]]
== 先決條件

. 用於中心叢集的 Red Hat OpenShift 叢集（高於 4.5 版本）
. 用於託管叢集的 Red Hat OpenShift 叢集（高於 4.4.3 版本）
. 叢集管理員存取 Red Hat OpenShift 叢集
. Red Hat 訂閱 Kubernetes 高階叢集管理


高階叢集管理是 OpenShift 叢集的附加元件，因此根據中心叢集和代管叢集所使用的功能，對硬體資源有一些特定的要求和限制。在調整叢集規模時，需要將這些問題納入考量。如需詳細資訊，請參閱 link:https://access.redhat.com/documentation/en-us/red_hat_advanced_cluster_management_for_kubernetes/2.2/html-single/install/index#network-configuration["網路組態要求"^]。

如果中心叢集具有用於託管基礎架構元件的專用節點，且您只想在這些節點上安裝 Advanced Cluster Management 資源，則需要相應地為這些節點新增容差和選擇器。如需更多詳細資訊，請參閱 link:https://access.redhat.com/documentation/en-us/red_hat_advanced_cluster_management_for_kubernetes/2.2/html/install/installing#installing-on-infra-node["在基礎架構節點上安裝"^]。
